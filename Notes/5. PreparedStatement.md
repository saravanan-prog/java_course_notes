### PreparedStatement

PreparedStatement is a precompiled SQL statement.

#### Advantages
- Faster execution
- Prevents SQL Injection
- Reusable
- Better performance
#### Example
```
PreparedStatement ps = con.prepareStatement(
    "INSERT INTO students VALUES (?, ?)"
);

ps.setInt(1, 101);
ps.setString(2, "Saravanan");

ps.executeUpdate();
```
### Common Methods

| Method            | Description                   |
| ----------------- | ----------------------------- |
| `setInt()`        | Sets integer value            |
| `setString()`     | Sets string value             |
| `executeUpdate()` | Executes INSERT/UPDATE/DELETE |
| `executeQuery()`  | Executes SELECT               |
