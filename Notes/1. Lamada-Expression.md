# What is a Lambda Expression in Java?

- A lambda expression is a short way to write an anonymous function (a function without a name). 
- It was introduced in Java 8 to make code cleaner and more functional.

### 🔹 Basic Syntax
```
(parameters) -> expression

or

(parameters) -> {
    // multiple statements
}

```
🔹 Simple Example
### Without Lambda:
```
Runnable r = new Runnable() {
    public void run() {
        System.out.println("Hello");
    }
};

Treade t1 = new Thread(r) 
t1.start()
```
### With Lambda: Used like:
```
interface Add {
    int sum(int a, int b);
}

Add obj = (a, b) -> a + b;


System.out.println(obj.sum(5, 3)); // 8

```
### 🔹 Where Lambdas Are Used

Mostly with functional interfaces (interfaces with only one abstract method), like:

- Runnable
- Comparator
- Callable
- Custom interfaces

🔹 Real Example (Sorting List)
```
List<String> names = Arrays.asList("Ram", "John", "Abi");

names.sort((a, b) -> a.compareTo(b));

```

🔹 Key Benefits

- Less code (no boilerplate)
- More readable
- Enables functional programming style
- Works well with Streams API
