# 🔹 What is a Stream?

A Stream is a sequence of elements that you can process in a functional style (filter, map, sort, etc.)

🔹 Why Streams?

Before Java 8:

- More loops
- More boilerplate code

With Streams + Lambda:

- Cleaner
- Shorter
More readable


### 🔹 Basic Example : Without Stream:
```
List<String> names = Arrays.asList("Ram", "John", "Abi");

for (String name : names) {
    if (name.startsWith("A")) {
        System.out.println(name);
    }
}
```
###### With Stream + Lambda:
```
names.stream()
     .filter(name -> name.startsWith("A"))
     .forEach(name -> System.out.println(name));

✅ Output:

Abi
```

#### 🔹 Key Operations

###### 1. filter() → Select data
```
names.stream()
     .filter(name -> name.length() > 3)
     .forEach(System.out::println);
```
###### 2. map() → Transform data
```
names.stream()
     .map(name -> name.toUpperCase())
     .forEach(System.out::println);

✅ Output:

RAM
JOHN
ABI
```
###### 3. sorted() → Sort data
```
names.stream()
     .sorted()
     .forEach(System.out::println);
```
###### 4. collect() → Convert to list
```
List<String> result = names.stream()
    .filter(name -> name.startsWith("J"))
    .collect(Collectors.toList());

System.out.println(result);

✅ Output:

```

### 🔹 Real Example (Very Important)

Get names with length > 3, uppercase, sorted
```
List<String> result = names.stream()
    .filter(n -> n.length() > 3)
    .map(String::toUpperCase)
    .sorted()
    .collect(Collectors.toList());

System.out.println(result);
```
