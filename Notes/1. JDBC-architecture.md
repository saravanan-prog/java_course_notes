# JDBC Architecture

- Java Database Connectivity (JDBC) is a Java API used to connect Java applications with databases 
- like MySQL, Oracle Database, and PostgreSQL.

### JDBC Architecture Flow
```
    Java Application
       ↓
    JDBC API
       ↓
    DriverManager
       ↓
    JDBC Driver
       ↓
    Database
```
#### Components
###### Java Application
- Your Java program.
###### JDBC API
- Interfaces and classes used to interact with the database.
###### DriverManager
- Loads and manages database drivers.
- Creates database connections.
###### JDBC Driver
- Vendor-specific implementation that communicates with the database.
###### Database
- Stores the data.
