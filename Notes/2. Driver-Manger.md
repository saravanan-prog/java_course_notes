# DriverManager

DriverManager is a class used to establish a connection between Java application and database.

Example
```
Class.forName("com.mysql.cj.jdbc.Driver");

Connection con = DriverManager.getConnection(
    "jdbc:mysql://localhost:3306/studentdb",
    "root",
    "password"
);

```
### Important Methods

| Method               | Description                 |
| -------------------- | --------------------------- |
| `getConnection()`    | Creates database connection |
| `registerDriver()`   | Registers driver            |
| `deregisterDriver()` | Removes driver              |
